# Impulse UI review, 2026-09-01

Screenshots: `docs/UI_Screenshots/2026-09-01_review/` (gitignored, the Home shots contain real dictations). Captured from the shipped dashboard (`dashboard.html`) launched from source with the current user data, plus the recording pill on the desktop.

## What ships vs what is in the repo

The installed app (`%LOCALAPPDATA%\Programs\Impulse`) contains only `dashboard.html`. The React dashboard under `src/whisper_local/ui/impulse-dashboard/` is never packaged, and its `dist/` predates the 2026-08-24 redesign. It still shows "Welcome back, User", the stray pink dot on the logo tile, a "WL" avatar, hard-coded challenges (142/160 WPM, 823/1000 words), a hard-coded achievements list, and a "Ctrl + Space" shortcut that is not the real hotkey. Nothing below applies to it. Archive it or delete it so nobody screenshots, demos, or fixes the wrong UI.

## Top 5 moves, in order

1. **Open the shipped dashboard at ~1100 x 740 instead of 420 x 700.** `gui_host.py` sizes the legacy window at 420 x 700 (`win_w = 1200 if is_impulse else 420`). At 420 px the page hits the 980 px mobile breakpoint: the sidebar becomes a two-row horizontal nav, badges collide with labels ("Achievements9/14", "ChallengesDaily"), the nav scrolls away with the content, the settings modal wraps every label one word per line, and the Models cards read "Picks / the / best / model / for / this / machine". The same page maximized (reviewed in-session, not saved to disk) already looks right: sidebar, hero, Velocity and Live Feed side by side. This is the single biggest visual fix and it is one line plus a min-size.
2. **One currency.** The rank card says 138,605 XP, the chip on the same screen says 25,293 XP, and the progress bar says 25,293 / 57,654. The header number is `stats.totalWords` bound to a label that says XP (`dashboard.html` line 77). Label it words, or bind it to `stats.xp`. A paying user cannot tell what they are being scored on.
3. **Velocity and Weekly Words show zero while Live Feed shows fresh 311-word dictations.** "0 Weekly Words" sits next to "12 Day Streak". The 7-day chart is flat. Either the chart reads a different store than the feed, or the `date` column the query groups on is not being written. Not verified which. Until it is, the home screen contradicts itself.
4. **Make the pill findable and let it confirm.** Idle opacity is 0.0 and idle size is 10 x 10 (`AmbientPill.py`), so the pill does not exist on screen when idle. The README still says "click the floating status pill" to open the dashboard, which is impossible. After a dictation it disappears within half a second with no "pasted, 42 words" moment. Suggest: a faint idle dot (opacity ~0.35) that opens the dashboard on click, and an 800 ms success or failure flash with the word count.
5. **Remove the in-page minimize and close buttons and the "Copy Last" toolbar row.** They duplicate the OS title bar directly above them and cost a full row at the top of every view. "Copy Last" belongs on the hero card next to the shortcut, or on the latest Live Feed item (which already has Copy).

## Home

- Hero card ("Dictate anywhere, Hold Ctrl + Win and talk, or tap Ctrl + Win + Alt") is the right lead. Keep it. The kbd styling is the best-looking element in the app.
- Gamification chips (Lvl 11, XP, streak, weekly) plus the rank card with avatar "I" and "Voice Virtuoso" take the top third before any dictation shows. Collapse to one slim strip under the hero: words today, average WPM, streak. Move level and rank into the Challenges view.
- Live Feed renders full transcripts. A 311-word dictation fills the whole column. Clamp to 3 lines with an expand affordance, keep the Copy button and the word count.
- The "LIVE" badge and "RECENT" label repeat on every card and carry no information. Show a relative time instead ("2 min ago").
- Velocity chart has no y-axis, no values on hover, and identical bars, so it reads as decoration even when data exists. Put the number for today above it and label the bars with counts.

## Snippets / Dictionary

- Each view opens with a 40 px display heading plus a subtitle plus a second explainer card ("The stuff you should not have to re-type") before the first useful control. At 420 px the Add form is below the fold. Lead with the input row, one line of help under it.
- The Dictionary "Add Word" button is a full-width hot pink block, the only element that loud in the app. Match the Snippets "Add new" size.
- Snippet cards show trigger and replacement in monospace with a "Trigger" / "Replacement" label pair; fine, but the Copy and Delete icons are 18 px targets with no hover state at this size.

## Achievements / Challenges

- Achievements at 420 px stacks four full-width rarity cards (Common 4/4, Rare 4/6, ...) before the grid, so the first achievement is about four screens down.
- Challenges nests three levels of bordered cards (page card, Daily Missions card, Word Count card). Flatten to one card per challenge, like the React page did. The React page's row layout (icon, title, XP, single progress bar with "82 / 100") is the better pattern to port.
- Records strip at the bottom shows "Longest Session N/A". Hide records that have no value.
- Speed Goal shows "153 / 120 WPM" with a check mark, so a completed target still renders as a fraction over its target. Show "Done, 153 WPM".

## Settings

- Five tabs wrap at 420 px so License sits alone on a second row. Fixed by the window-size change.
- General exposes Stylization Profile, Ollama Model and Ollama Endpoint to every user. Ollama is not shipped and the app has the context router disabled for that reason. Hide those rows unless an Ollama endpoint answers.
- "Record Shortcut" row: the label, the value box ("Ctrl + Win") and a pink button that also says "Record Shortcut". Rename the button "Change".
- Models tab: the "CURRENT: BASE (8.0 GB VRAM)" green all-caps line overflows its card. Put current-model status once, above the three cards, in normal case.
- Data tab is good: Export, Share Telemetry with an honest description, Snapshot. Keep.
- Audio: the VAD slider is the only blue element in a pink and green app. Use the accent.

## Visual system

- Palette works: near-black ground, pink accent, green secondary, amber for streaks. The gradient progress bars (pink to green) are distinctive; keep them as the one gradient.
- Two display sizes are doing too much work. Outfit at ~40 px for view titles and ~28 px for card titles inside a 400 px column is what makes everything feel cramped. At the larger window size, drop view titles to 24 px.
- Card radius, border and glow are consistent. Nested cards break it (see Challenges).
- The logo tile (pink brain glyph in a rounded square) and the "Impulse" wordmark are fine. The avatar circle "I" does nothing; drop it or use it for the license state.

## Pill (recording HUD)

- Recording state: dark pill, pink mic, pink dotted level meter, docked bottom-center with a 16 px margin. Reads clearly, right size, does not fight the desktop.
- No visible ARMED vs RECORDING difference at a glance, no processing spinner that lasts long enough to see, no result state. See move 4.

## Not captured

- First-run wizard: running `first_run_wizard.py` standalone crashes (`tk.BooleanVar` created before the Tk root exists, line 136). The bundled path may be fine; it is untested here.
- Tray menu: right-click on the taskbar was blocked in this tooling.
- Settings tabs and the maximized layout were reviewed in-session but are not among the saved files; the saved set covers Home, Snippets, Dictionary, Achievements and Challenges at the shipped window size.
